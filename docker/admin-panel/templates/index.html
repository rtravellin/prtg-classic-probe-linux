Core connection & identity
Changes write to the Wine registry. The container entrypoint re-asserts core server / port / access key from compose env on every boot — to persist those permanently, also update the compose file. A probe restart applies changes.
Access key

8 hex characters. Must match the key set in the core (Setup ▸ Probes).

Logging level

Verbose debug logging for the probe process.

WMI sidecar targets

Per-target credentials the Impacket bridge uses (read-only here; passwords masked). Edit /opt/wmi-bridge/targets.json on the host.

TargetUsernameDomainPassword
Service control

Start/stop drive Wine's SCM (net start/stop PRTGProbeService). “Restart container” recreates the whole probe via the Docker API.
